Aegis first. Upgrade only if the retry fails.

Hybrid = base + Aegis retry cost + remaining failure ratio × fallback cost. Retry cost includes every recorded failure-only retry, divided by the original task count. Failed attempts are paid. All costs use 100,000 original tasks.

Greedy ladder: each model gets one base attempt and one enforced Aegis retry on failure. Choose the next model by the lowest cost/pass ratio among models with a higher observed after-Aegis pass rate for this task and effort. Skip levels that do not reduce estimated cost. Keep a fully qualified model as the final fallback. Latency is not part of the score.

Estimate only. We did not run a linked model ladder. The estimate applies each model's observed average pass rate to tasks that reach it. Models can fail on the same cases, so the ladder can cost more than this estimate. A 10/10 result does not prove zero failures. A final fallback with zero estimated reach remains in the plan. No combined pass-rate claim or hybrid confidence interval is made.

The CSV also keeps the original weighted formula, p × base cost + (1 − p) × fallback cost. That old formula excludes failed cheap attempts and all Aegis retries. It is not the hybrid bill shown here. “Both efforts” averages the low/high estimates.

Method and limits

This is task evidence. It is not a universal model rank.

How to read the cost

  • Cost per 100,000 attempts is total task cost divided by attempts, then multiplied by 100,000.
  • Cost per 100,000 successes is total task cost divided by successful tasks, then multiplied by 100,000.
  • Failed attempts remain in the successful-task cost.
  • A route with no successful run has no successful-task cost.

Evidence limits

  • Each objective task has one low-effort and one high-effort run per route.
  • The completed pilot combines 120 earlier reasoning runs and 90 executed tool workflows across 15 routes.
  • The live campaign adds 10 new repetitions for each route, effort, and task. Its statistics exclude the pilot.
  • Every failed tool workflow triggers one enforced Aegis retry with fresh fixture state.
  • The historical one-shot experiment has 61 enforced retries and 18 recoveries. It uses a different task contract.
  • The long reasoning task used a common 4,096-token output limit.
  • DeepSeek and Claude use OpenRouter. GPT uses the direct OpenAI API.
  • The earlier Aegis Method Lite arm covered 41 failures and recovered nine. It remains a separate prompt-only condition.
  • The coding pilot has one high-effort run per route.
