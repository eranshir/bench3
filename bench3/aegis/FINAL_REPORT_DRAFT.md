## What this run measures

Whether **live enforcement** of the Aegis method changes measured adherence and outcomes on
bench3 agentic tasks vs prose guidance alone — the enforcement-lift measurement that the
mithran-hq/aegis smoke-5 ladder could not run (blocked on #1285 in the codex-native path;
bench3 can run it because DSH's permission surface is harness-controllable).

Arms (ADR 0043 Rule 6 ladder rungs 3-4): **aegis-guided** (method prose + explicit IR schema,
no gate) vs **aegis-enforced** (identical instructions + workspace-resident gate that reverts
pre-plan mutations). Identical instructions; the only difference is whether the gate is live.

## Honesty boundary (issue #1623)

Supported conclusion is PROCEDURAL: "Aegis can require and record plans, frozen commitments,
evidence, and closure attempts." This run does NOT establish that Aegis makes an agent
reliable, correct, or complete. The enforcement-lift numbers constrain the measurement's
claims; they do not validate the product.

## The gate (enforcement mechanism)

The bench3 gate (gate_validator.py + gate_daemon.py) is the DSH-adapter analogue of the codex
PreToolUse hook: the workspace git baseline is snapshotted, and any mutation outside .bruno/
before the Aegis IR validates (plan + children with falsifiers, per bruno.local_ir.plan.v1)
is reverted and logged to gate-events.jsonl. Authoring .bruno/ is always allowed. A canary
(pre-plan write reverted) proves the gate is live. Recorded divergence per Rule 3: the gate
validator is bench3-pinned, not the aegis release binary.

## How to read the tables (generated at completion)

1. **Pass rates / pass^k**: identical resolution under both arms would mean enforcement is
   outcome-neutral (the smoke5 expectation); a difference is the outcome delta.
2. **Enforcement lift (Δres, Δcomp)**: positive = enforcement changed trajectories.
   McNemar p on paired resolution; bootstrap 95% CI on continuous deltas. No causal phrasing
   where CI includes 0.
3. **Gate denies/reverts**: with the explicit IR schema in the payload, self-compliance
   dominates (models author the plan first); the gate fires only on genuine pre-plan
   mutations. Zero denies is a valid enforced-arm outcome, not a broken gate (canary + transcript prove liveness).
4. **Compliance vector**: plan_valid, children-with-falsifiers, closure — scored on ONE rubric
   (#1629), per artifact not per turn (#1630), closure per ADR 0059 semantics (#1636).
5. **Contamination**: symmetric containment (no directional leakage) is the isolation signal;
   the 0.20 threshold is SWE-bench-calibrated and bench3 calibration is an open item (ADR 0043).
6. **Enforcement time tax**: median enforced vs guided wall time.
